### 0.3 C8 极性：**别换成瓷片**

10-24 那版写过「可用 1210 瓷片 100µF 替代」，**这条撤回**。理由：
100µF 陶瓷在 4.2V 直流偏置下容量会掉到 30µF 以下，功放低频一大就破音。钽电容不掉容，该用还得用。

正确做法：**焊之前用万用表点一下**。一支笔搭任意 GND（J5 第 2 脚、SW1 焊盘都行），另一支点 **C8 左焊盘**：

- 响 → 左焊盘是 GND，**正极在右边**
- 不响 → 左边就是正极，按丝印装

钽电容本体上那条**深色带是正极**（和铝电解相反）。接反通电会炸。

| AVX TAJ 规格（10V 档 / 6.3V 档） | 10V（TAJB107M010） | 6.3V（TAJB107M006） |

### 0.9.3 C1 C4 C6 C7 C9 用 X7R：没问题，比原定还好（2026-11-01 20:05）

**结论：可以，放心焊。** X7R 不是「凑合」，是把原来的 X5R 升级了。

| 介质 | 温度范围 | 容值偏差 | 5V 偏压下还剩多少（10uF 0805 25V） | 判 |
|---|---|---|---|---|
| **X7R** | **−55 ~ +125°C** | ±15% | 约 **50~65%** → 5~6.5uF | ✓ **买这个** |
| X5R | −55 ~ +85°C | ±15% | 约 50~65%（和 X7R 接近） | ✓ 也能用，原定就是它 |
| **Y5V / Z5U** | −30 ~ +85°C | **+22/−82%** | **只剩 10~20%** → 1~2uF | ✗ **绝对不能买** |

三条理由：

1. **温度上限 125°C vs 85°C**。板子装壳后最热的是 U3（充电时）周围，壳内大概 45~55°C。X5R 的 85°C 其实也够，X7R 相当于多一层保险。
2. **容值偏差两者一样 ±15%**，X7R 并没有更准，它的优势只在温度上。
3. **价格差很小**（0805 10uF 25V 这个规格 X7R 只比 X5R 贵几分），没有理由不选。

**红线是 Y5V / Z5U**：便宜一半，但 10uF 在 5V 下只剩 1~2uF，等于没焊，而且温漂巨大。看到这三个字母直接跳过。

#### 五颗各自的角色（顺便确认容值够不够）

| 位号 | 挂哪 | 干什么 | 5V 偏压后约 5uF 够不够 |
|---|---|---|---|
| **C1** | VSYS | LDO 输入储能 | ✓ XC6220 只要求输入 ≥1uF，5uF 富余 5 倍 |
| **C4** | +3V3 | U1 的 3V3 脚旁，和 C3(100nF) 挨着 | ✓ **这颗最要紧**，WiFi 发射时 350mA 瞬态全靠它 + C3 |
| **C6** | VBUS | TP4056 输入 | ✓ 线性充电器对输入容值要求宽松 |
| **C7** | BAT | TP4056 输出 | ✓ 同上 |

**MLCC 掉容是所有高容值陶瓷的通病，不是 X7R 的错** —— 介质层越薄、容值越大的越明显。这就是为什么板上还要有 **C8 100uF 钽电容**：它才是功放真正的大水库，C9 只是补高频。这个分工本来就是这么设计的，不用改。

## 三、喇叭怎么选（这次新增）

功放 **MAX98357A 输出是 BTL 桥接**，两只脚都是输出，**任何一脚都不许接地**。

### 硬指标（不符合就别买）

| 参数 | 要求 | 为什么 |
|---|---|---|
| 阻抗 | **8Ω**（不要 4Ω） | 4Ω 在 5V 下峰值 3.2W、电流 700mA，电池 1C 顶不住，VSYS 会被拉塌 → 3V3 掉压 → WiFi 重启 |
| 功率 | **≥0.5W**（1W / 2W 更保险） | VSYS 4.2V 时 8Ω 满推约 0.9W。标 0.5W 的**必须把音量压到 40%**，否则烧音圈 |
| 厚度 | **≤5.5mm**（含腔体）；薄型喇叭 ≤4mm | 背盖里要和 6mm 的电池齐平，太厚会顶壳 |
| 灵敏度 | **≥82dB**（16×9 这类多在 80~85） | 0.3W 驱动在 1 米内能到 75~80dB，闹钟够、放歌偏小 |
| 接线 | **焊线版**（两根裸线） | J7 是 2.54 排针焊盘；带 PH2.0 端子的要剪掉 |

### 四个具体选项

| 方案 | 规格 | 尺寸 | 价 | 外壳要做什么 | 结论 |
|---|---|---|---|---|---|
| **A · 20×14 腔体喇叭** | 8Ω 2W | 20×14×**5.5** | ¥3~6 | **只开出声孔**（腔体自带） | 声音最好，但要占掉电池旁那条缝 |
| B · Φ20 薄型喇叭 | 8Ω 1W | Φ20×**3.6** | ¥2~3 | 必须自己做后腔 ≥2mm + EVA 泡棉圈密封 | 薄 2mm，但外壳多一道工序 |
| C · Φ20 带端子 | 8Ω 2W | Φ20×4 | ¥3 | 同 B，且要剪端子 | 不如 A 省事 |
| **D · 1609 超薄（现选）** | 8Ω **0.5W 或 1W** | 16×9×**3** | **¥1.2/个**（4 个 ¥4.8） | 前脸对出声孔 + 泡棉圈密封 | 声音比 A 小一档，但**唯一能塞进 9mm 窄缝**的。**同尺寸有 1W 版就买 1W**，见下面「8Ω 1W 行不行」 |

**D 的三个前提（缺一不可）：**
1. **必须是 8Ω**。16×9 这一个尺寸 4Ω 和 8Ω 都有卖，标题不写。用万用表量直流电阻：
   **8Ω 喇叭实测 6.5~7.5Ω，4Ω 实测 3.2~3.7Ω**。量出来 4Ω 就别用（满功率 2W+，音圈直接烧）。
2. **多半是 0.5W 额定**，功放满推会到 0.85~0.9W ⇒ 固件音量压到 **40% 左右（约 -8dB）**。
3. **前腔必须密封**：喇叭前脸和外壳出音孔之间垫一圈泡棉，别让前后声短路；
   背面直接开在外壳内腔就行（内腔容积够大，不用另做后腔）。


### 8Ω 1W 的 1609 能不能用（2026-11-01 20:11）

**能用，而且比 0.5W 的保险 —— 同尺寸优先买 1W。** 上面硬指标本来就写着「≥0.5W（1W/2W 更保险）」。

先纠正一个常见误解：**喇叭标的「1W」是它能承受的上限，不是它会输出 1W。**
实际响度由 VSYS 电压和固件音量决定，**换 1W 的不会变响，也不会更费电**。

| | 8Ω **0.5W** | 8Ω **1W** |
|---|---|---|
| 功放满推约 0.9W 时 | **超载 1.8 倍** → 必须压到 40% 音量 | 超载 1.1 倍 → 可放到 60~70% |
| 烧音圈风险 | 大音量或低频多就烧 | 小 |
| 续航 | 一样（耗电只看音量，不看标称） | 一样 |
| 灵敏度 | 通常 84~86dB | 同尺寸往往**低 1~2dB**（音圈更粗、振膜更硬） |
| 最大响度 | 被功率卡住 | **更大** |

★ **唯一可能的心理落差**：1W 版在**同音量下**可能听起来略小一点（灵敏度低 1~2dB），
但音量能往上开，净结果更响。别以为买错了。

**下单前确认三件事：**

1. **阻抗仍是 8Ω**。1609 这个尺寸 4Ω 和 8Ω 都有卖，标题基本不写。
   万用表量 DCR：**8Ω 读 6.5~7.5Ω**；读到 3.2~3.7Ω 就是 4Ω，不能用（4Ω 满推 3W+、峰值 700mA，电池扛不住）。
2. **厚度仍要 3mm（最多 3.5）**。有些 1W 版加厚到 4mm，**塞不进那条 9mm 窄缝**。
3. **磁体直径**。1W 的磁钢通常更大（Φ10 对 Φ8），16×9 的框里如果磁体凸出，会顶到屏或电池。到手先拿板子比一下。

**固件音量**：1W 版可以给到 **-4dB（约 60%）**，比 0.5W 版的 40% 明显响，音圈仍有约 40% 热余量。
仍然**不要开满** —— 满推 0.9W 会让 VSYS 掉压，WiFi 有概率重启。

淘宝关键词：
- A：`20*14 腔体喇叭 8欧2W`（也叫 **2014 腔体喇叭**，常见于小音箱/玩具，自带塑料腔体和导音口）
- B：`20mm 超薄喇叭 8欧1W 3.5mm`（要选**带焊点**的，不要带线的耳机式）
- **D：`1609 喇叭 8欧 0.5W`**（16×9×3 超薄，手机拆机料最多；下单前一定问清阻抗，标题基本不写）

**不要买**：4Ω 的、压电陶瓷片、带蓝牙/功放小板的一体喇叭、Φ28 以上的（板上和壳里都放不下）。

### 2415（24x15）8Ω 1W：声音是升级，但装不进现有的缝（2026-11-01 20:18）

**电气：完全没问题。** 8Ω 1W 就是上面说的最优选，而且 2415 比 1609 好听一大截：

| | 1609（16x9） | **2415（24x15）** |
|---|---|---|
| 振膜面积 | 144mm² | **360mm²（2.5 倍）** |
| 灵敏度 | 84~86dB | **88~90dB（高 3~5dB）** |
| 同样 0.3W 时 | 基准 | **响 1.5~2 倍** |
| 低频 | 基本没有 | 能出一点（240Hz 以上） |
| 规格 | 8Ω 0.5W | **8Ω 1W** ✓ |

**物理：塞不进那条缝。**

缝宽是 **34 − 25 = 9mm**（板宽减电池宽），1609 的 9mm 正好卡进去，2415 的 **15mm 宽进不去**。

三条路，按推荐排序：

| 方案 | 怎么做 | 代价 |
|---|---|---|
| **① 外壳加宽 6mm**（推荐） | 内腔 34 → **40mm**，右侧留 15mm 给喇叭 | 整机宽 6mm，要重画外壳和出声孔位置。**声音值得** |
| ② 换窄电池 | 602535(25宽) → 502030 或 402535 | 500mAh 掉到 300~400mAh，续航少 1/3 |
| ③ 回到 1609 | 保持现有外壳 | 声音小一档，但 3 分钟搞定 |

### ★★ 不管放哪，这一条不能破：磁体不许进天线正上方

**`x 9.3~24.8` 且 `y > 44` 这一块是 U1 的天线区，喇叭（连同磁钢）的投影绝对不许压进去。**

磁体是金属，贴在天线附近会让 2.4G **失谐 + 涡流吸收**，WiFi 距离从 30m 掉到个位数。
而且这个故障 **DRC 查不出、万用表量不出、通电也一切正常** —— 只有实测信号强度才看得出来，
最容易装进壳里以后才发现。

**最稳的放法：整颗喇叭的投影都在 `x > 25`**（板右侧那 9mm 缝的延长区）。
这样横向完全避开天线，y 方向随便放。方案 ①「外壳加宽到 40」正好能做到 —— 喇叭占 `x 25~40`。

补充两条：
- **厚度选 ≤4mm**（2415 有 3.5 / 4 / 5 三种）。背盖要和 6mm 的电池齐平，5mm 的会顶壳。
- 出声孔跟着挪：2415 的孔面积给 **50~60mm²**（8 个 Φ2.8 或 4 个 Φ4），别开在振膜正中央的悬边上。

### 怎么接

`J7.1 → 喇叭一脚`，`J7.2 → 喇叭另一脚`，**不分正负**（接反只是相位反，单声道听不出）。
线用 **26~30AWG**，留 **40~50mm**，两根**绞在一起**再走，能少拾一点功放开关噪声。

### 外壳必须做的三件事

1. **出声孔总面积 ≥50mm²**（8 个 Φ2.5 或 4 个 Φ4）
2. **后腔 ≥2mm**（A 方案喇叭自带，B 方案得靠外壳掏）
3. **喇叭边缘用 EVA 泡棉圈压紧密封**，否则前后腔串气，低音全没了、声音发闷

> 选 D（16×9）时出声孔可以小一半：**30~40mm² 就够**（6 个 Φ2.5），孔别开在振膜正中央的悬边上，
> 稍微偏一侧声音更松。喇叭用原来的背胶粘在外壳内壁即可，四周再补一圈泡棉。

### 音量怎么定

| A/B/C（8Ω 1~2W） | **-6dB（约 50%）** | ≈0.5W | 2 小时以上 |

## 五、七个必须避开的坑

1. **U1 是 LGA 封装，烙铁焊不了。** 必须热风枪（350℃ 30~40s）或加热台。没有就找维修店吹一下。
2. **FPC 座必须「下接」翻盖卧式。** 已选定的 `C19269981` 就是下接，**别换成上接**（同尺寸同外观，
   插进去很紧也可能不导通，且从外观完全看不出）。翻盖式对 FPC 厚度敏感，这块屏是 0.2mm，正好。
3. **U2 是 SOT-23-5，U3 是 SOP-8**，两个封装完全不同，别拿错。
   XC6220：1=VIN 2=VSS 3=CE 4=NC 5=VOUT —— **和 ME6211 完全一致**，换料不用改线。
   （**CE 必须接 VSYS**，B 型没有内部下拉，悬空 = 可能无输出）。
4. **电池极性。** 焊 J5 前用万用表量电池引线：**红线 = 正、黑线 = 负**。
   接反 = TP4056 和电池保护板一起报废，严重会起火。
5. **TP4056 的 PROG 电阻（R5）不能省。** 悬空不充电，接 0Ω = 1A 大电流会把 500mAh 电池打伤。
6. **C8 钽电容有极性，接反会炸。** 3528 本体上一条**深色带**是**正极**（和铝电解相反！），
   丝印上的 `+` 号那一端对准正极。上电前用万用表量一次：C8 正端对 GND 应是 4V 左右，
   反了就是 0 或者芯片已经没了。
7. **U4 是 TQFN-16-EP 3×3、0.5mm 间距，没有外伸脚**，底面中间还有一块散热盘（EP）必须焊上，否则大音量会触发热保护。必须用钢网/针管点锡膏 + 热风，
   **绝对不能拿烙铁硬拖**（脚全在底下）。芯片底部的散热焊盘**必须焊上**，否则大音量时过热保护。
