# 原理图分块布局（V3 · 33 元件）

> 目的不是好看，是**接线不出错**：每个功能块内部的元件紧挨着，块内画短线；
> 跨块只放**同名网络标签**，一根长线都不拉。分块排好之后，用「布局传递」把每一块
> 一次性送到 PCB，PCB 的分区也跟着自然成型。

---

## 1. 三层结构

| 层 | 用什么画 | 规则 |
|---|---|---|
| **块内** | 真实导线 | 只画 1~2 个元件之间的短线，尽量 < 10mm |
| **块间** | **网络标签**（放置 → 网络标签，快捷键 `N`） | 相同名字即同一网络，名字必须逐字一致 |
| **电源与地** | 电源符号 / GND 符号 | `GND` 一律用符号，**不要用网络标签画 GND** |

| 网络 | 从 | 到 | 备注 |
|---|---|---|---|
| `VBUS` | J2 / D1 阳极 | U3.4 U3.8 · Q2.G · R8 | 充电与栅极两处都要接 |
| `VSYS` | D1 阴极 · Q2.S | U2.VIN · U2.CE · U4.VDD · C1 · C8 · C9 | 功放走这条 |

## 4. 画框和标题

1. **放置 → 矩形**：填充设「无」或 5% 灰，线型虚线，线宽 0.5。先画大框，再往里放元件。
2. **放置 → 文本**：字号 10~12，写在框的**左上角内侧**或下方居中，跟参考图一致。
3. 框之间留 8~12mm 空隙，不要贴在一起 —— 标签要写在外面。

> 框只是视觉分组，**不影响电气**。真正定义连接的是网络标签和导线。

## 5. 布局传递（这一步才是分块的价值）

| 项 | 说明 |
|---|---|
| 入口 | 顶部菜单 **设计 → 布局传递**；也可右键 → 布局传递 |
| 快捷键 | **Ctrl + Shift + X** |
| 前提 | PCB 已生成并**处于打开状态** |
| 动作 | 原理图里**框选一块的元件** → 触发 → 自动跳到 PCB，这些封装悬浮在鼠标上，点一下落地 |

**顺序照下面来，PCB 分区就对了**：

| 顺序 | 框选 | 落到 PCB |
|---|---|---|
| 1 | 电源切换与 LDO | 左侧中部 `x0.5~8` |
| 2 | 充电 + USB 输入 | 左上 / 左侧 |
| 3 | 电池接口 | 左侧中上 |
| 4 | 主控（只框 U1） | 置顶居中 `(17.018, 37.173)` |
| 5 | 屏幕接口 J1 | 底部居中 `(17.00, 11.05)` |
| 6 | 背光 Q1 R4 | 右下 `(27.4, 11.5)` |
| 7 | 按键 SW1 SW2 | 底边两侧 |
| 8 | 音频 U4 C8 C9 J7 | 底部 `x10.8~23.4` |
| 9 | Flash U5 C11 | 右侧 `(29.5, 20.5)` |

**四个坑**：

1. **PCB 必须先打开**，否则不生效；工程里有多块 PCB 时只对当前那块生效。
2. 传递后是「悬浮待放置」，**必须点一下**才落地。
3. **只框元件**，不要连导线、文本一起框进去（多选了会被一起带过去）。
4. 落地位置就是**原理图里这块的相对排布** —— 原理图排得紧，PCB 上就落得整齐；
   所以第 1 步画框时，块内元件就要按实物顺序摆好（比如充电块里 C6 贴 U3 的电源脚）。

- [ ] `GND` 全部用符号，没有用标签
- [ ] U1 上 19/20/21/25/34/35/36 的悬空 ✕ 已删；32/33 保持 ✕
- [ ] ERC：**未连接项 = 0**，只剩悬空警告
