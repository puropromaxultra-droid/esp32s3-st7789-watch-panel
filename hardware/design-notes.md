## 1. 板与叠层

- 板框 **32 × 42 mm**，厚 **1.6 mm**（嘉立创免费打样标准厚度，也是唯一免费选项）
- **四层**：F.Cu / In1 / In2 / B.Cu；In1 走 USB 与模组信号，In2 走 CC，
  **B.Cu 原先完全空着（只有地铜皮），V2 的两条按键线就走 B.Cu**
- 四面 GND 铺铜 + 边缘缝合过孔，全板共 **73 个过孔**（57 个 0.6/0.3 缝合孔 + 16 个 0.45/0.3 布线孔）
- 天线净空 keepout：**(9.9, 32.7)–(26.5, 38.5)**，四层都禁铺铜/走线/过孔。
  ⚠️ v1 曾写成 (7.9,32.8)–(24.1,38.4)——向左偏了 2.2mm，模组天线段实际在
  x 10.14..26.26 / y 32.77..38.16，右半条天线当时仍压在 GND 铜皮上，已修正。
  铺铜脚本会按 U1 的 courtyard 核对该窗口，改动模组位置后要同步改 `add_pour.py` 的 KX0..KY1。
  **V2 换成 1U 后这条 keepout 仍然留着**：IPEX 座和软天线正好落在这块无铜区，少一层地
  在天线底下，比铺满铜好。
- 设计规则：线宽 ≥0.15、净距 0.15、过孔 0.5/0.3、孔环 ≥0.1、孔到铜 0.25、铜到板边 0.3

## 2. Type-C：从 12P 换成 16P（XKB U262-16XN-4BVC11）

原用 HRO TYPE-C-31-M-12，其 A/B 两排焊盘**交错排布**，DP/DM 四个焊盘互相封死，
0.15/0.15 规则下无出线通道（这是之前一直差 3 根线的根因）。

换成 XKB U262-16XN-4BVC11 后所有焊盘在**一条线上**，每个焊盘垂直出线互不交叉。

**★ 方向返工（2026-10-17 23:40）**：初版 J2 旋转 90° 摆放，按数据手册核对后发现
**插口朝板内**（信号焊盘在壳体尾端、插口在前端，90° 旋转把前端指向了 +x）。
已改为 **rot=270、x=2.225**：插口面距板边 0.15mm、前壳脚距板边 0.35mm（手册推荐布局），
信号焊盘列 x=5.895。KiCad 库此封装无 3D 模型，渲染图看不出来，DRC 也不查——
这是当时没发现的原因。新走法（rot270 后 y=21+local_x）：

| 焊盘 | y | 网络 | 走法 |
|---|---|---|---|
| A1/B12 | 17.8 | GND | 实心铺铜连接（ZONE_CONNECTION_FULL，右侧补地孔 7.0,17.8） |
| A4/B9 | 18.6 | VBUS | F.Cu → x=8.60 主干 → U2/C1 |
| A5 | 19.75 | CC1 | F.Cu → 过孔(7.30) → In2 x=3.30 → R1 |
| B7 | 20.25 | USB_DM | F.Cu → 过孔(7.90) → In1（y=20.25 至 16.30 折 y=19.00 绕 DP 立柱） |
| A6 | 20.75 | USB_DP | F.Cu → 过孔(7.30) → In1 合并（x=7.30）→ y=21.75 右行 → 17.35 下行 |
| A7 | 21.25 | USB_DM | 同 B7（合并 x=7.90） |
| B6 | 21.75 | USB_DP | 同 A6 |
| B5 | 22.75 | CC2 | F.Cu → 过孔(7.90) → In2 x=3.85（避开后壳脚焊盘 x≥4.28）→ R2 |
| A9/B4 | 23.4 | VBUS | 同 A4/B9 |
| A12/B1 | 24.2 | GND | 实心铺铜连接（右侧补地孔 7.0,24.2） |

DP/DM 落点 (17.35/18.20, 19.65) 打孔回 F 面进模组焊盘（y=18.0）；
DM 的 In1 在 y=19.00 从 DP 落点下方绕过（层上净距 0.35，DP 的 F 面 stub 在另一层互不干扰）。
**物料**：XKB U262-16XN-4BVC11（星坤，淘宝约 ¥1，16P 卧贴，引脚定义与 12P 兼容）。

## 3. 电源

- USB 5V → **ME6211C33M5G-N（SOT-23-5，500mA，1=VIN 2=GND 3=CE 4=NC 5=VOUT）** → 3.3V
  - **V2 换件理由**：V1 用 XC6206P332MR（200mA / 限流 250mA），而 ESP32-S3 发 WiFi 峰值
    355mA —— 一发包就限流掉压、BOR 复位，表现是「连上 WiFi 就重启」。电容救不了
    （350mA 撑 1ms 要 1000µF）。不开 WiFi 时整机 ~100mA，V1 是够的。
  - **CE（3 脚）必须并到 VBUS**，悬空 = 关断 = 量不到 3.3V。
  - 热账：3.3V@120mA 平均 → (5−3.3)×0.12 ≈ 0.2W，SOT-23-5 + 四层铺铜可接受；
    WiFi 发包瞬间 0.6W 是毫秒级尖峰，靠铜皮热容吸收。
- VBUS F 面主干 x=8.60 从连接器右侧下来，0.2mm 线宽（约 1A 裕量）；
  y=26.30 左行分两路：x=6.825 进 C1，x=1.10 下行到 U2，在 y=27.35 / y=29.25 各右拐一次，
  分别进 **U2.1（VIN）** 和 **U2.3（CE）**
- U2.5（VOUT）→ x=5.55 竖直到 y=28.30 → C2；+3V3 再经 R3 两焊盘之间的走廊桥到右半区
- CC1/CC2 各 5.1k 下拉（R1/R2）
- U2.2（GND）焊盘只有 0.6 高，孔压上去会吃锡 → 向右拉到 x=4.338 打地孔
  （夹在 pad5@27.35 与 pad4@29.25 正中，两侧各余 0.42）；C5.2 同样单独拉地孔

## 4. 布局

- U1 模组居中偏右 (18.2, 25.0) 转 180°，LCD 信号全部朝上边靠近 FPC 座
- J1 = Molex 502244-2430（24P 0.5mm 卧式）在上沿 y=11.08，开口朝板边
- J2 Type-C 在左沿 x=2.225, y=21.0，rot=270，插口朝板外（2026-10-17 方向返工后）
- U2/C1/C2/R1/R2/C5 在连接器下方；Q1/R4 在右上角（背光）
- 屏轮廓丝印画在 B 面：2.75,10.0 → 29.25,39.5（26.5 × 29.5mm）
- **J3/J4 按键接口（V2 新增）**：板顶那条 y=0~7 是唯一没被屏盖住的区域（屏从 y=10 开始），
  正好放两个 2.54 排针。J3 在 (5.0, 2.6)、J4 在 (29.6, 2.6)，都在 FPC 进线区（x 9.5~22.5）之外。
  排针本体 2.5mm 高，压在屏外面，不会顶到屏。
- **WiFi（V2 已解决）**：V1 不开 WiFi 的两个硬伤都已处理 —— LDO 换 500mA（§3）；
  模组换 **MINI-1U**，PCB 天线换成 IPEX 座，天线用小软线引到板外，屏怎么压都挡不到。
  V1 的顾虑「LCD 金属背板贴在天线正下方 1.6mm」在 1U 版上不成立了。

## 5. 引脚分配（ESP32-S3-MINI-1）

| 信号 | GPIO | 说明 |
|---|---|---|
| LCD_SCK | 12 | SPI2 时钟 |
| LCD_MOSI | 11 | 数据 |
| LCD_CS | 10 | 片选 |
| LCD_DC | 9 | 数据/命令 |
| LCD_RST | 14 | 复位 |
| LCD_BL | 13 | 背光 PWM（经 SI2302 低边 NMOS） |
| LCD_IM | 3V3 直连 | **必须高电平 = SPI 模式**（当年黑屏的根因） |
| FPC 14 脚 RD | 3V3 直连 | SPI 模式无用，但照抄原板拉高（悬浮输入有漏电风险） |
| USB_D- | 19 | 固定 |
| USB_D+ | 20 | 固定 |
| **BTN_A** | **4** | 按键 A（模组脚 8）→ J4.2，内部上拉，按下 LOW |
| **BTN_B** | **5** | 按键 B（模组脚 9）→ J3.2，内部上拉，按下 LOW |

> ⚠️ 面包板固件的按键是 **IO10 / IO11**，在这块板上已被 LCD_CS / LCD_MOSI 占用，
> 移植时必须改成 IO4 / IO5。这两个脚是干净的（无 strapping、无 ADC 冲突）。

## 6. 物料（见 gerber/BOM.csv）

U1 **ESP32-S3-MINI-1U-N8** + IPEX 2.4G 天线；J1 Molex 502244-2430；J2 XKB U262-16XN-4BVC11；
U2 **ME6211C33M5G-N（SOT-23-5，500mA）**；Q1 SI2302（A2SHB，兼容 AO3400A）；
J3/J4 2.54mm 1×02 排针；R 0603×4；C 0603/0805×5。
按键是外接（排针 + 两根线），不是板上贴片轻触开关。无 ESD 管（D+/D- 直接到模组 19/20 脚）。

## 7. 生产（嘉立创免费打样 · 已对照官方工艺页复核）

- 层数 **4**、尺寸 **32×42mm**（10×10cm 内）、5 片、单片交货 —— 全部落在免费券范围内
- 板厚 **1.6mm**、铜厚 1oz、表面处理喷锡（沉金要加钱，会顶破 ¥20 券）
- **阻焊只能选绿油**：官方规则"单/四/六层板仅支持绿油"，绿油本身就是免费的唯一选项，不是妥协
- 工艺核对（对照嘉立创《制造工艺要求》）：最小线宽/间距 0.15（四层要求 ≥0.09）、
  最小孔径 0.3（四层要求 ≥0.2）、过孔盘 0.5（保证单边环宽 0.1）、铜到板边 0.3（锣边要求 ≥0.3）
  —— 全部达标；0.45 盘配 0.3 孔环宽仅 0.075，低于嘉立创四层标准，故取 0.5
- Type-C 外壳脚是 0.6×1.2 / 0.6×1.7 长圆槽孔（0.6 刀铣），定位孔 0.65 NPTH，钻孔文件只有 0.3/0.6/0.65 三种刀
- 贴片：J2/U2/Q1/R/C 可上 SMT；U1、J1 建议手焊（模组返修容易，座子怕高温）
- 固件：现有 `lcd_fast` 改引脚定义即可，逻辑不动
- **领券门槛**：用非嘉立创 EDA（本项目用 KiCad）领通用券，需上月实付 ≥¥20；否则用嘉立创 EDA 可直接领 2 张/月。免费券 30 天有效，免费单包邮

## 7.1 装配注意（屏的位置）

屏（26.5×29.5）贴背面时**必须靠板的上沿放**：丝印框 2.75,10.0–29.25,39.5，屏占满整个框，
FPC 从屏的上沿出来绕到正面 J1（y=11.08）。
⚠️ 按这个位置贴，屏的金属背板正好盖住模组原来的天线段（y 32.8~38.2）。
**这就是必须用 1U 版的原因**：1U 没有板载天线，IPEX 座在模组顶面（朝上），
把软天线从板边（建议下沿或右侧）引出去就行，屏挡不到。
板顶 y=0~7 这条 7mm 高的横带是屏盖不到的区域，J3/J4 两个按键排针就放在这里，也别在这条带里加高元件。

## 8. 已知瑕疵（不影响功能）

1. B 面屏轮廓丝印 x=2.75 竖线与 J2 屏蔽壳通孔焊盘开窗相交 → 丝印会被裁掉两小段。
   屏贴背面本来就盖住这条线，纯外观问题。
2. 屏轮廓与 J2 座子 courtyard 只差 0.06mm（实际金属件间距 0.58mm），装配不冲突。
3. USB 沉板量已核（2026-10-17 23:40）：J2 rot=270 后本体前沿在 x=−1.50，即**伸出板边 1.5mm**，
   外壳定位脚全在板内（最近处距板边 0.35mm）。卧贴 USB-C 的正常态，插头金属壳正好包住插座前沿，
   不用挪。DRC 剩下的 2 条 silk_edge_clearance 就是这段伸出体的丝印被板边裁切，纯外观。
