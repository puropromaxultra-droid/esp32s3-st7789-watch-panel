# 一体化板 · 焊完到底能干什么

日期：2026-10-21（10-23 加 J6）　对应：`EDA-连线表.md`（**V3** · 27 元件 / 22 网络 / 34×50mm）

---

## 一句话结论

**这块板焊完 = 一个插着能跑、拔了还能跑 3 小时的桌面天气时钟。**

六页可翻页，WiFi 拉天气与校时，板载天线不用外接线，电池内置，两个按键从外壳背面按。

### 移植要改的引脚

```cpp
#define PIN_SCK  12    // 面包板 IO4
#define PIN_MOSI 11    // 面包板 IO5
#define PIN_CS   10    // 面包板 IO6
#define PIN_DC    9    // 面包板 IO7
#define PIN_RST  14    // 面包板 IO8
#define PIN_BL   13    // 新增：背光（面包板直连 3V3）
#define BTN_A     4    // ★ 面包板是 IO10，本板已被 LCD_CS 占用
#define BTN_B     5    // ★ 面包板是 IO11，本板已被 LCD_MOSI 占用

#define PIN_VBAT  1    // ADC，电池电压（分压 ÷2）
#define PIN_CHRG  2    // 低电平 = 正在充电
```

### 电池相关的两段代码

```cpp
// 电量：ADC 读的是分压后的电压，乘 2 还原
float vbat = analogReadMilliVolts(PIN_VBAT) / 1000.0f * 2.0f;
int pct = constrain(map((int)(vbat * 100), 330, 420, 0, 100), 0, 100);

// 可选：想夜里多撑 1~2 小时才降功率。已经不需要靠它保命了
// （Q2 压降 0.02V + XC6220 dropout 0.07V，电池 3.2V 时 3V3 还有 3.11V）
esp_wifi_set_max_tx_power(8);   // 约 8dBm，峰值 355mA → 250mA
```

## 二、这版硬件仍然做不了的

| 想做的 | 为什么不行 |
|---|---|
| **断电走时**（电池拔了时间不丢） | 没有 RTC 芯片。但**有电池就一直在跑**，只有电池耗尽才会丢；而且一联网就校回来 |
| **本地温湿度 / 光照** | 没有 I2C 引出。下一版加 4 个焊盘（3V3/GND/SDA/SCL）就能接 AHT20、BH1750 |
| **声音 / 喇叭** | 没有 I2S、没有功放 |
| **快充** | TP4056 是线性充电，5V/255mA，充满约 2.5 小时 |
| **边充边用满功率 WiFi + 满速充电** | 两者叠加约 550mA，超过 500mA 的 USB 口；用 5V/1A 以上的头就行 |

## 三、电池和充电的三个数字

| 状态 | 电流 | 说明 |
|---|---|---|
| 电池供电，播 GIF | ~100 mA | 500mAh → 约 5 小时（不联网） |
| 电池供电，每小时刷一次天气 | 平均 ~130 mA | **约 3.5 小时** |
| 充电（R5 = 4.7k） | 255 mA | 空电到满约 2.5 小时 |

**低电量行为**（固件里要写）：电压低于 **3.15V** 时关 WiFi、只播 GIF；低于 **3.05V** 熄屏待机。
保护板在 2.4~3.0V 硬截止，ESP32 在 3.0V 以下先崩，所以留 0.05V 余量提前降级。

> 改电源之前这两个阈值是 3.5V / 3.4V —— 等于电池最后 30% 完全用不上。现在压到 3.15V。

## 四、按键怎么用

```
SW1（左，x=7.3）  = BTN_A = 上一页
SW2（右，x=26.6） = BTN_B = 下一页
长按 1.2s         = 回时钟页（在时钟页长按 = 立刻刷天气）
```

两个开关焊在**板正面（元件面）**，也就是朝外壳内部那一侧。外壳背盖上做两个按键柱，
从背面顶它们。**外壳那一面要开两个 ⌀5 的孔 + 内部两个柱子**，柱高按开关高度定
（6×6 开关本体约 4.3~5mm 高，柱长 = 壳体到开关的距离，留 0.2mm 预压）。

## 五、装配顺序（顺序错了会白焊）

```
1. 嘉立创下单（34×50，4 层，¥30）
2. 先焊 U3 + D1 + Q2/R8 + C6/C7 + R5/R6/R7（充电电路）  ← 先单独验充电
3. 焊 U2 + C1/C2/C5/R1/R2/R3（主电源），上电量 3.3V   ← 不过这步，后面全白焊
4. 焊 U1 模组（热风枪 350℃ 30~40s 或加热台）
5. 焊 J2 Type-C、Q1/R4、J1 FPC 座、SW1/SW2
6. 插屏排线（**断电插**），烧固件，串口 `t` 自检
7. 最后接电池（**先量极性**），装壳
```

### 第一次上电的顺序

1. **不接电池、不插屏**，限流 150mA 上电 → 量 3V3 = 3.3V
2. 插屏 → 出画面、背光亮
3. 断电接电池 → 量 `BAT` = 电池电压、`+3V3` 仍 3.3V
4. 拔掉 USB → 屏应该继续亮（说明 Q2 通路正常）
5. 插回 USB → 量 `CHRG` 脚为低（正在充电）

第 4 步是最容易出问题的一步：拔了 USB 就黑屏，说明 **Q2 源漏焊反 / 栅极接错**，或者电池没接上。
